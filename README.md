# 林小雪 AI 私人助理

基于 [Hermes Agent](https://github.com/NousResearch/hermes-agent) + MiniMax 多模态大模型构建的私人AI助理，运行在 Mac Mini 本地，为高老板提供工作和生活自动化服务。

## 核心功能

### 🏠 全屋定制装修比价分析
- 输入：手写报价单截图（微信发送）
- 处理：MiniMax VLM 视觉识别 → openpyxl 结构化数据提取 → Excel 汇总
- 输出：11个空间完整报价单，总价自动计算，含商家手写备注还原
- 案例：某全屋定制报价单 ¥125,749.92，含玄关柜/餐边柜/电视柜/阳台柜/老人房/儿童房/书桌/书柜/岛台/橱柜

### 📈 股票市场实时监控
- 东方财富 MCP 行情接口（无需 API Key）
- 每日自动推送涨跌排名、异动预警
- 支持自选股实时价格监控

### 💬 全平台消息推送
- 微信 / 飞书 双平台消息收发
- 飞书 Bot 文件/图片/富文本消息
- iMessage 原生收发

### 📋 Apple 原生集成
- Apple Notes 笔记创建与读取
- Apple Reminders 提醒事项管理
- Apple FindMy 设备追踪

### ⏰ 定时自动化任务
- 每日股票涨跌报告（下午4点推送飞书）
- 每日家庭清理汇报（晚10点执行）
- 定时任务调度（自然语言 Cron）

### 🔧 商用车知识管理系统
- 发动机冷却系统 LLM Wiki 知识图谱
- D3.js 可视化 Dashboard
- 多设备 iCloud 同步访问

## 技术栈

| 层级 | 技术 |
|------|------|
| Agent 框架 | Hermes Agent (Nous Research) |
| 多模态模型 | MiniMax-M2 (视觉理解/搜索/TTS) |
| 行情数据 | 东方财富 MCP (新浪/东财公开接口) |
| 消息平台 | 飞书开放API / 微信 |
| Apple 集成 | macOS 原生 CLI (imessage/remindctl/memo) |
| 可视化 | D3.js / openpyxl |
| 运行环境 | macOS Mini (Apple Silicon) |

## 系统架构

```
用户（微信/飞书/语音）
        ↓
  Hermes Gateway（统一入口）
        ↓
  ┌─────────────────────────────────┐
  │       林小雪主 Agent             │
  │  • 任务规划与信息综合            │
  │  • 多工具协调调度                │
  │  • 记忆与用户画像               │
  └─────────────────────────────────┘
        ↓
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 东方财富MCP│  │MiniMax MCP │  │ 飞书API   │
  │ (行情数据)  │  │(视觉/搜索) │  │ (消息推送) │
  └──────────┘  └──────────┘  └──────────┘
        ↓
  ┌──────────┐  ┌──────────┐
  │ Apple原生 │  │ 定时调度  │
  │ (iMessage)│  │ (Cronjob) │
  └──────────┘  └──────────┘
```
